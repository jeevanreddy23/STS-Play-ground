# Learning path - Slope stability

A suggested walk through the 26 slope stability skills, staged from
observation to judgement. The staging is heuristic (grouped by what each skill
*does*), not a syllabus — skip what you already hold, and let a gap found in a
later stage send you back to an earlier one. That return trip is the point:
the path is walked recursively, not once.

**How to use it.** Pick the next unread note in the earliest stage with gaps.
Read it against its source. Then drill [[Flashcards - Slope stability]] until the deck
is clean, and when field work exercises one of these skills, capture what
differed — see [[Learning loop]].
