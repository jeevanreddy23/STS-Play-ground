# AS 1726 soil and rock description

AS 1726:2017 *Geotechnical site investigations* is the Australian standard that
sets out how ground is described and logged. It is the reason two engineers
logging the same core should produce comparable descriptions.

> The standard itself is copyright and is not reproduced here. Clause numbers
> are recorded so the passage can be found; check the actual document before
> relying on any of this on a job.

## What it governs

- The vocabulary for soil and rock description, and the order terms appear in —
  see [[Soil description order]].
- Weathering and strength classification for rock — see
  [[Rock weathering classes]] and [[Rock strength classes]].
- Sampling and in-situ test reporting requirements.
- What a borehole log must show — see [[Borehole log conventions]].

## Why the order matters

The description order is not stylistic. A log is read by people scanning a
column for a change in material, so the governing term comes first and the
qualifiers follow. Writing "brown clay, high plasticity" instead of
"CLAY: high plasticity, brown" breaks the scan.
