# Select class-based end bearing, shaft adhesion and modulus design values for Sydney sandstone and shale

> **Source:** `Pells Paper on Foundations on sandstone and shale in The Sydney Region.pdf` (Section 4.3 and Tables 5a-5b (pp 23-25); boundary footing guidance p 24), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** Ultimate and serviceability end-bearing pressures, ultimate shaft adhesion and typical mass modulus chosen by rock class for limit state design of pads and sockets, with boundary-footing adjustments where needed.

## Inputs

- Rock class (I-V) established by the three-criteria classification
- Substance UCS (several serviceability entries are expressed as 0.5 x qu with class caps)
- Footing/socket geometry and proximity to property boundaries or excavations
- Confirmation of clean sockets with roughness R2 or better where shaft adhesion is used

## Procedure

1. Classify the rock, then read ultimate end bearing, serviceability end bearing (pressure for settlement under 1% of minimum footing dimension), ultimate shaft adhesion, and typical mass modulus from Table 5a (sandstone) or 5b (shale) on pp 24-25 of the paper; do not quote values from memory.
2. Note the table footnotes: ultimate end-bearing values occur only at large settlements (over ~5% of minimum footing dimension); adhesion values presume clean R2+ sockets, and shale values may need reduction for smear.
3. Use ultimate values only within a limit state check with the recommended geotechnical reduction factors; use serviceability values for settlement-governed sizing.
4. For footings near property boundaries where uniform settlement is desired, reduce boundary-footing pressure to about 60% of that for remote footings (boundary footing defined by centre-to-boundary distance less than the footing width normal to the boundary).
5. Where an adjacent excavation exists below footing level, check kinematic failure of joint-bounded blocks; in the Sydney CBD the dominant joint set strikes NNE dipping 65-90 degrees, making N-S faces particularly prone.

## Decision rules

- End bearing is usually settlement-controlled, so arbitrary nominal boundary reductions are illogical; use the settlement-equalising 60% guideline or explicit analysis.
- Pick modulus within the class range according to whether the rock sits at the upper or lower bound of the class.

## Checks

- Class assignment satisfies all three criteria (strength, defect spacing, seams).
- Load-displacement linearity assumption valid up to the serviceability values used.
- Adhesion only claimed where inspection confirms cleanliness and roughness.

## Common errors

- Using ultimate end-bearing values at working-load settlements.
- Applying sandstone adhesion values to smeared shale sockets.
- Ignoring kinematic block failure next to deep excavations.

## Caveats

- Table values in the OCR contain obvious character corruption; always read the numbers from the published tables, not this extract.
- Design reference only: values must be verified against the source tables and reviewed by a qualified engineer before use.

## Standards cited

AS 2159-1995 (piling, limit state), NSW Ordinance 70 (superseded practice discussed for context)
