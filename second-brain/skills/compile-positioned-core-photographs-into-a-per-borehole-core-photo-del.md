# Compile positioned core photographs into a per-borehole core-photo deliverable

**Outcome.** Raw field snaps of core boxes become a client-ready document with one page per borehole: a perspective-corrected ('positioned') core photo under a standard header giving job, location, survey coordinates, rig, logger and date, issued as Word plus PDF.

## Inputs

- Raw core box photos (phone/camera, often oblique, with the STS board and in-box depth labels visible)
- Borehole survey data: easting, northing, surface RL (mAHD)
- Drilling metadata: contractor, drill rig, logger initials, coring dates
- STS Word template with logo header and core-photograph layout

## Procedure

1. Select the best raw photo of each core box (all trays visible, board legible, minimal glare).
2. Perspective-correct and crop each photo so the core box fills the frame square-on with the depth numbers running down the left edge — the 'positioned' image.
3. Rename each positioned image to its zone/area and borehole ID (e.g. MP4-BH01, MP5-BH8) and save them in a 'Positioned' subfolder alongside the raw originals.
4. Insert one positioned image per page into the Word template under the title 'CORE PHOTOGRAPH OF BOREHOLE: <ID>'.
5. Complete the header table on every page: Job No, Location, Client on the left; Easting, Northing, Surface RL (mAHD) in the centre; Contractor, Drill Rig, Logger and Date on the right.
6. Repeat for every cored hole in the package, then export the compiled document to PDF and file both docx and pdf in the job's core-photos folder.

## Decision rules

- Keep raw, positioned and compiled versions as three separate layers; never overwrite raw photos with corrected ones.
- One borehole per page; where a hole needs several boxes, use additional pages under the same borehole title.
- Use surveyed coordinates and RL in the header, not phone GPS from the photo, since the deliverable is the coordinate of record.
- Date field may span a range (e.g. 19-20/03) when coring of a hole crossed days.

## Checks

- Borehole ID in the page title matches the ID readable on the photo board and in-box strip within the image.
- In-box depth labels visible in the positioned image are consistent with the stated hole depth and the borehole log.
- Easting/northing/RL in each header match the survey schedule for that hole.
- Every cored hole in the job appears exactly once; page count equals borehole count.

## Common errors

- Pairing the wrong photo with a borehole when several boxes were shot in one session (UUID/IMG filenames make mix-ups easy before renaming)
- Skipping the perspective correction so scale varies across the image and depth rows cannot be compared
- Leaving header coordinates blank or copying them from the previous page without updating
- Compiling from WhatsApp-recompressed copies instead of the original-resolution photos

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
- The tool used for perspective correction is not evidenced (only its output); any image editor that squares and crops the box achieves the same result
- Whether the compilation is issued standalone or appended to the factual report is not evidenced here
