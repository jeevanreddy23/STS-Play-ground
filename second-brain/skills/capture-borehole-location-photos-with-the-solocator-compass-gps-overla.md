# Capture borehole location photos with the Solocator compass-GPS overlay

**Outcome.** Each investigation-location photo carries a burnt-in compass ribbon, true bearing, decimal coordinates with stated GPS accuracy, altitude and timestamp, and is renamed to its borehole ID so location and view direction are verifiable later without any external metadata.

## Inputs

- Smartphone with the Solocator app installed and GPS/compass enabled
- Borehole / test-location schedule for the day
- Clear line of sight to the location being documented

## Procedure

1. Open Solocator (not the plain camera) when photographing borehole or test locations so the overlay is burnt into the image.
2. Frame the location with recognisable site context (plant, stockpiles, structures) and check the compass ribbon along the top shows the intended view direction.
3. Confirm the overlay banner is populated before shooting: bearing in degrees with (T) true-north basis, decimal latitude/longitude, GPS accuracy (e.g. ±4 m, ±5 m), and altitude in metres; the date-time stamp appears bottom-right.
4. Take the shot only once the reported GPS accuracy is acceptable (single-digit metres); wait for the fix to settle if it is worse.
5. Take multiple frames per location a few seconds apart as insurance (files export as Solocator-YYYY-MM-DD HH-MM-SS.jpg so bursts stay ordered).
6. After the shoot, rename or duplicate the keeper photo for each investigation location to its ID (e.g. BH1.jpg, BH2.jpg) and upload both the renamed keepers and the raw Solocator-named files to the job's site-photos folder in Drive.

## Decision rules

- Use Solocator when the photo must document WHERE a location is and WHICH WAY the camera faced (borehole positions, test locations); a time-GPS-only overlay app is sufficient when direction does not matter.
- If GPS accuracy shown in the banner is worse than about ±5-10 m, move to open sky or wait before shooting rather than accepting a poor fix.
- Keep the raw timestamp-named file alongside the renamed BH-ID copy so the capture time remains traceable even after renaming.

## Checks

- Overlay shows all five elements: compass ribbon, bearing with (T), lat/long to 6 decimal places, ±accuracy, altitude; plus the timestamp in the corner.
- Bearing on the ribbon matches the sketched/planned view direction for that location.
- Renamed file IDs match the borehole IDs on the field sheet and site plan for the same day.

## Common errors

- Shooting with the normal camera app so no overlay is burnt in and location must be reconstructed from EXIF alone
- Accepting a photo while the GPS fix is still coarse, giving coordinates tens of metres off
- Renaming files to BH IDs without keeping the originals, losing the capture-time evidence
- Mismatching renamed IDs against the borehole schedule when several nearby holes are shot in one session

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
- STS also uses the TimePhoto app for time-GPS-stamped site photos (separately mined practice); which app is preferred per task is not documented in the records
- Solocator settings (true vs magnetic north, units, banner fields) are app configuration; the records only evidence the output format, not the configured settings screen
