# Complete a DCP and Perth penetrometer deep test field sheet (Form S26)

> **Source:** [Google Drive — 2520E-G/Field Sheets/2427E-G.pdf (page 1)](https://drive.google.com/file/d/197Eg1nMVzS96OTO8ecyfFmeI2G55vbiY/view) (Completed S26 sheet with two DCP tests (P1 from 0.7m, P2 from 0.0m) in silty clay, blows per 100 mm recorded to ~1.5 m, header warning and footer codes visible). Reconstructed from STS's own

**Outcome.** A completed 'Dynamic Cone & Perth Penetrometer - Deep Test' worksheet recording penetration resistance in blows per 100 mm for up to three test locations, with soil description and refusal coding.

## Inputs

- Form S26 (Dynamic Cone & Perth Penetrometer - Deep Test, Date of Issue 10/07/25, Revision 2)
- DCP or Perth penetrometer apparatus with known apparatus number
- Test locations, start depths (from pre-drilled hole or surface)

## Procedure

1. Fill the header: Project, Client, Project No. / STS No. (e.g. 32422/2427E-G), Technician initials, Sheet _ of _.
2. Circle the test method on the printed line: AS 1289.6.3.2-DCP, AS1289.6.3.3-Perth, or RTA T161-DCP.
3. For each of the three test columns fill: Site No. (with start depth noted in brackets, e.g. 'P1 (from 0.7m)', 'P2 (0.0)'), Chainage if applicable, Start Depth (m), Soil Description (e.g. 'Silty CLAY, m-plasticity, brown, trace sand'), Moisture Condition (e.g. dry-moist).
4. Drive the penetrometer and record blows per 100 mm in the depth rows, which run 0.00-0.10 up to 5.90-6.00 m in 0.10 m increments.
5. Use the printed codes where full blows are not recorded: R = Refusal, D = Discontinued, S = Stone, * = Pre-Drilled Hole.
6. Record the Apparatus Number, and circle Y/N for 'Apparatus Function and drop height Checked'.
7. Date the sheet and have it signed off in Checked By.

## Decision rules

- NEVER combine DCP and Perth tests on the same work sheet — printed as a warning on the form header.
- When testing from the base of a pre-drilled or excavated hole, record the start depth against the Site No. and use the * code for the pre-drilled interval.
- Stop and code R (refusal), D (discontinued) or S (stone) rather than forcing counts.

## Checks

- Test method circled matches the apparatus used
- Apparatus function and drop height check circled Y before testing
- Blows recorded continuously from start depth with no unexplained gaps
- Sheet numbering completed when the job runs to multiple sheets

## Common errors

- Mixing DCP and Perth results on one sheet (explicitly banned on the form)
- Omitting the start depth for tests begun below surface
- Leaving the apparatus number or drop-height check blank

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
- Based on one completed example sheet; handwriting of some blow counts is hard to read and values were not relied on

## Standards cited

AS 1289.6.3.2 (DCP) (printed on form), AS 1289.6.3.3 (Perth penetrometer) (printed on form), RTA T161 (DCP) (printed on form)
