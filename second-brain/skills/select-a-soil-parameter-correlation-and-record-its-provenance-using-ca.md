# Select a soil parameter correlation and record its provenance using Carter and Bentley

> **Source:** `Correlations of Soil Properties.pdf` (Carter & Bentley (1991), whole-book pointer; consult the chapter for the relevant property family), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** A defensible preliminary soil parameter chosen from the Carter & Bentley compendium, with its class basis, applicability limits and citation documented, and with the value explicitly flagged as an estimate pending testing.

## Inputs

- Soil classification data (grading, Atterberg limits, USCS/AASHTO class)
- The target parameter (e.g. density, permeability, compressibility, shear strength, CBR, swelling potential)
- Carter & Bentley, Correlations of Soil Properties (Pentech Press, 1991)

## Procedure

1. Locate the chapter covering the target parameter (the book is organised by property family: classification systems; natural and compacted density; permeability and grading; consolidation and settlement; shear strength; California Bearing Ratio; shrinkage and swelling).
2. Check the stated region of applicability of the candidate correlation (soil type, plasticity range, stress state) before adopting it.
3. Take typical values or correlation outputs as preliminary estimates only; the authors state such predictions can never substitute for proper testing.
4. Record the exact table/figure, page and edition alongside the adopted value, plus the classification inputs used.
5. Plan confirmation testing for any parameter that ends up governing design.

## Decision rules

- Prefer correlations tied to classification tests actually performed for the site over generic typical-value tables.
- Where two correlations disagree materially, carry the range forward rather than picking the favourable end.

## Checks

- Correlation applicability limits verified against the site soils.
- Every correlation-derived value distinguishable from measured values in the design record.

## Common errors

- Using typical-value tables outside the soil class they describe.
- Letting a correlation-derived parameter silently become a 'measured' value in later reports.
- Skipping confirmation testing on design-governing parameters.

## Caveats

- The OCR of this excerpt is heavily garbled (large sections mirrored/scrambled), so no numeric content from the extract should be trusted; use the printed book.
- Design reference only: any adopted value requires verification against the source tables and qualified review before use.

## Standards cited

BS/ASTM classification test methods referenced within the book
