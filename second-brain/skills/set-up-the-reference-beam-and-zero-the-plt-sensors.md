# Set up the reference beam and zero the PLT sensors

> **Source:** `050-Setup Proceedure for PLT Draft 4 Feb 2024.pdf` (Sections F-G, pp. 4-6), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** The engineer can install the displacement reference beam clear of the loaded zone, align the transducer on the plate centre, and zero both displacement and force channels before loading.

## Inputs

- Folding reference beam with adjustable feet and star knobs
- Displacement transducer and holder
- Electronic measuring box
- Assembled plate / cylinder / ball joint loading train

## Procedure

1. Unfold the reference beam and place it roughly 1.5 m from the loading plate (p. 4).
2. Mount the displacement transducer in its holder and align the beam so the transducer tip sits at the centre of the loading plate, handling the transducer carefully.
3. Free the knob on the front L-shaped arm so the arm can travel up and down, level the beam with the adjustable feet, and fine-align the front support arm using its bubble level.
4. Confirm every star knob is tight.
5. Put the bubble level indicator near the outer edge of the loading plate and adjust it until the bubble is centred, so plate tilt during the test will be visible.
6. Position the electronic box near the operator, mechanically adjust the displacement sensor to read approximately zero (near fully retracted) using the star knob and display, then set it to zero electronically.
7. Confirm there is slack between the hydraulic cylinder/extensions and the counterweight so the load cell carries no force, then zero the force channel on the electronic box.
8. Route and clip the cables tidily along the reference beam.
9. Recheck the plate bubble level indicator is still centred before starting the load sequence (p. 6).

## Decision rules

- Zero the force sensor only while the cylinder is demonstrably unloaded (visible flex in the train) (p. 6).

## Checks

- Transducer tip is at the plate centre and nearly fully retracted at zero.
- Plate bubble remains centred at the end of setup.
- All star knobs tight; cables clipped so they cannot snag.

## Common errors

- Damaging the displacement transducer during beam alignment.
- Zeroing the force sensor while residual load is on the cylinder.
- Leaving star knobs loose so the beam shifts during the test.

## Caveats

- Steps 5-7 of the test-performance section are blank in this draft, so the loading sequence itself must come from the AX01a manual.
- The 1.5 m beam offset is given as approximate; the document does not state a tolerance.
