# Select geotextile strength and filtration class

> **Source:** `RMS Spec D & C R63.pdf` (Clauses 2.1-2.2, 4.1 and Annexure R63/E (Ed 2 / Rev 0, May 2013)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** The correct geotextile strength class and filtration class for a separation/filtration application, matched to fill size, subgrade strength and soil fines.

## Inputs

- Application category (separation under embankments unsaturated/saturated, trench/edge drains, drainage behind structures, under rock revetment)
- Nominal maximum stone size D90 of the fill or revetment
- Subgrade CBR and saturation state
- Site soil grading (D15, D50, coefficient of uniformity, fines content)

## Procedure

1. Classify the application into the specification's category system (G1-G5).
2. Pick the strength class (A-E) from the application table using fill D90 and, for drains/drainage layers, depth or subgrade CBR; saturated/soft-ground applications demand higher classes for the same stone size.
3. Pick filtration requirements (equivalent opening size, permittivity, flow rate) from the soil-type columns based on the fines fraction and permeability of the site soil.
4. Confirm survivability considering subgrade condition, fill particle size and construction/placement process, not just the table lookup.

## Decision rules

- Strength class escalates with larger D90 and weaker/saturated subgrades; some large-stone saturated cases are simply not permitted with any class (RMS Spec D&C R63 Annexure R63/E Table E.1 notes).
- Filtration EOS ceilings tighten as soil fines increase (finer soils need smaller opening sizes) with matching minimum flow/permittivity values (Annexure R63/E Table E.1).
- UV stability requires at least 50% retained strength after 500 hours exposure testing (Clause 2.1.3).

## Checks

- Application-specific site details (D90, CBR, soil type) recorded in the project annexure table.
- High-strength basal reinforcement under embankments on soft ground is outside this spec - use the appropriate reinforcement spec.

## Common errors

- Selecting on strength alone and ending up with an opening size that clogs or pipes in fine soils.
- Using the unsaturated-ground category for a working platform on soft saturated subgrade.
- Applying this separation/filtration spec to reinforcement functions.

## Caveats

- Verify edition currency; the D&C variant mirrors base spec R63 Ed 4.
- Project deed documents and design drawings override.
