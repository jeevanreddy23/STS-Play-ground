# Skills

116 action-based skills mined from the practice documents, specifications,
papers and guides in the local reference library (`G materials`). Each note is a
paraphrased working aid pointing back to its source — what to do, what to check,
and where the authoritative wording lives.

**Ground rules.** Nothing here replaces the source document, the project
specification or a qualified reviewer. Numeric criteria are cited by clause or
page, not reproduced. Notes tagged `ocr-source` came from scanned documents
read by OCR — treat their details with extra suspicion. Confidence is the
extractor's, not an engineer's.

Not mined: the Australian Standards (see the section maps in
[[Reference library]]), the Core Geotech project reports (see
[[Project reports]]), and the reference textbooks (copyright — pointers only in
