# Mark up field density test locations on the project drawing set

> **Source:** [Google Drive — Field Density Test Locations Drawings/flomar_250819_071947.pdf](https://drive.google.com/file/d/10GjmsTKAub4YsIbRzo5KodVminNcTL9V/view) (Scanned stormwater-drainage overall plan (Marsden Park/Flomar package) hand-annotated with circled density test numbers across lots, sheet-boundary marks, and adhesive notes grouping batter tests and test-number ranges). **Outcome.** A scanned, annotated project drawing showing every nuclear-gauge density test number at its true location, linking test reports to the works area.

## Inputs

- Current civil/earthworks drawing for the area (e.g. the stormwater drainage overall plan shop drawing used on the Flomar/Marsden Park package)
- Density test numbers as issued in the day's test sequence
- Pen and adhesive notes; scanner or scan app

## Procedure

1. Print or carry the relevant project drawing (a shop drawing or overall plan that shows lot/building outlines and sheet boundaries).
2. At each nuclear density test, write the test number on the drawing at the tested location and circle it so numbers stay legible among linework.
3. Where many tests belong to one element (a batter, a building pad), group the numbers on an adhesive note stuck on that area of the drawing, stating the element and orientation (e.g. batter tests on the northern side) and the run of test numbers or number range.
4. Respect the drawing's sheet split (Sheet 1/2/3 boundaries marked on the plan) so each test falls on the sheet where the work is detailed.
5. Scan the marked-up drawing at day end (filename with job/date) and file it with the density test records so each report number can be located on plan.

## Decision rules

- Every test number on the day's gauge record must appear exactly once on the drawing - the drawing is the location index for the test reports.
- Use number ranges on notes only for genuinely contiguous sequences; isolated tests get individually placed circles.
- If the works area spans drawing sheets, mark the sheet boundary and continue on the correct sheet rather than crowding one plan.

## Checks

- Count of circled/listed numbers equals count of tests reported for the day/area.
- Sticky-note groups state which element they cover, not just numbers.
- Scan legibility check - circled numbers over dense linework are the first thing lost in a poor scan.

## Common errors

- Recording test locations only as chainages in a notebook with no plan markup, making later disputes about coverage hard to resolve.
- Placing a note listing many tests without anchoring which face/side of the element it refers to.
- Scanning at low resolution so handwritten numbers on the plan become unreadable.

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method

## Standards cited

AS 1289.5.8.1 (nuclear gauge field density), AS 3798 (earthworks testing frequency/coverage context)
