# Select the correct field density test method for an R44 earthworks lot

> **Source:** `r044.pdf` (Clause 7.3, Table R44.9 (Ed 5 Rev 1)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** The field density method matches the material's oversize content and layer thickness, so relative compaction results are valid and defensible.

## Inputs

- Particle size data - % by mass retained on the 37.5 mm AS sieve
- Material description (cohesive vs fine/medium cohesionless, gap graded)
- Layer thickness

## Procedure

1. Screen the material against Table R44.9: with low oversize (up to the first threshold) either nuclear gauge (T173) or sand replacement (T119) is allowed; in the intermediate oversize band only sand replacement is allowed; above the upper threshold report only the oversize percentage because relative compaction is invalid.
2. For fine to medium grained cohesionless, one-size or gap-graded materials, use the fixed volume extractive method (T165).
3. Reject nuclear gauge use where the layer exceeds 300 mm thickness (Clause 7.3.3).
4. At each location run the field density test and take a companion sample for laboratory maximum density and field moisture (T120 primary; T121/T180 only after correlation checks per Clause 7.3.5).
5. Apply the oversize correction to the laboratory maximum density per the nominated T105 appendix procedure and compute relative compaction via T166.

## Decision rules

- One test method per lot - choose before testing starts and do not mix (Clause 7.3.4).
- If oversize exceeds the upper Table R44.9 threshold, do not report relative compaction at all; the lot needs a procedure-based approach (e.g. rock fill rules) instead.
- Microwave/other rapid moisture methods are conditional on prior calibration against the oven method.

## Checks

- Smooth surface prepared at each sampling location
- Companion sample taken from the correct zone relative to the density test
- Oversize proportion and density determined for every sample, whatever the field method

## Common errors

- Nuclear gauge used on 20-40% oversize material or thick layers
- Relative compaction reported on very rocky fill where the result is meaningless
- Skipping the oversize adjustment of laboratory maximum density

## Caveats

- Verify the spec edition is current for the project; test method suites differ between R44 editions.
- Contract documents override.
