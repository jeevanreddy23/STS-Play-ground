# Classify vibration and select assessment criteria

> **Source:** `vibrationguide0643.pdf` (Sections 1.1, 2.1-2.2, Table 2.1 (DEC NSW, February 2006)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** The correct human-comfort vibration criterion (continuous, impulsive or intermittent/VDV) selected for a source, with excluded cases routed to the right framework.

## Inputs

- Source character and event count per assessment period
- Receiver type (critical area, residence, office/school/place of worship, workshop)
- Assessment period (daytime vs night-time)

## Procedure

1. Classify the vibration: continuous (uninterrupted over the period), impulsive (rapid build-up and decay, no more than three events per period), or intermittent (interrupted continuous, repeated impulses such as pile driving, or strongly varying continuous).
2. Route excluded cases elsewhere: blasting to the ANZECC blasting framework; structural damage, occupational exposure and motion sickness are outside this guideline.
3. Select the matching criterion set: weighted rms acceleration tables for continuous/impulsive; vibration dose values for intermittent.
4. Identify the governing axis convention relative to occupant posture (standing, seated, lying) and take the conservative case where posture is unknown.

## Decision rules

- Three or fewer events per assessment period: assess as impulsive; more: assess as intermittent via VDV (vibrationguide0643 Section 2.1, Table 2.1).
- Daytime is defined 7 am to 10 pm, night-time 10 pm to 7 am (vibrationguide0643 Table 2.2 note).
- Criteria are preferred/maximum goals, not mandatory limits; exceedances beyond maximum values after all feasible and reasonable mitigation trigger community negotiation (vibrationguide0643 Sections 2.3-2.4, 3.6).

## Checks

- Assessment location is where people are affected (inside buildings), with a justified transfer function if measuring outside.
- Building resonance considered - indoor values can exceed external ground values.

## Common errors

- Assessing pile driving against impulsive criteria when event counts make it intermittent.
- Applying human-comfort criteria to building-damage questions (different frameworks, e.g. DIN 4150-3).
- Assessing blasting under this guideline.

## Caveats

- Guideline is dated (2006, framed as interim pending BS 6472 revision); check for current NSW EPA policy before relying on it.
- Criteria are amenity goals; consent conditions and contract documents override.

## Standards cited

BS 6472-1992, BS 6841-1987, ISO 2631.1/2631.2, ANZECC 1990 blasting guideline, DIN 4150
