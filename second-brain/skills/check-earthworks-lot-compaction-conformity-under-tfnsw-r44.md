# Check earthworks lot compaction conformity under TfNSW R44

> **Source:** `r044.pdf` (Clauses 7.1-7.4, Table R44.10 (Ed 5 Rev 1, June 2020)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** An earthworks lot is statistically assessed for relative compaction and moisture and accepted or rejected against the correct location-based criterion.

## Inputs

- Lot location/type (mound, spoil, foundation treatment, formation layer, spill-through abutment zone, Selected Material Zone, verge/median)
- Field density, field moisture and laboratory maximum density results
- Annexure R44/A5 project moisture range
- Lot homogeneity evidence

## Procedure

1. Confirm lot homogeneity per Clause 7.3.2: material origin, appearance, moisture condition, compaction technique, response to compactors and underlying state must be substantially alike; carve out non-homogeneous areas as separate lots.
2. Verify moisture at compaction was inside the Annexure R44/A5 range everywhere in the lot (Clause 7.2); over-wet material must be dried (aeration, or lime with approval) before compaction.
3. Compute relative compaction per T166 with the oversize adjustment for material retained on the 37.5 mm sieve (Clause 7.3.6), then the characteristic value per Specification TfNSW Q, rounding both to 0.1%.
4. Compare the lower limit of the characteristic value against Table R44.10, which steps from 90% (mounds/spoil) through 95% and 98% tiers up to 100% (spill-through abutment zone) and 102% (Selected Material Zone layers).
5. Repair test holes with matching material compacted to match the surrounding layer (Clause 7.3.7).

## Decision rules

- Conformity requires the lower limit of the characteristic value to be at or above the Table R44.10 value for that location - individual test values alone do not decide the lot.
- Results from different test methods must never be combined in one lot's statistics (Clause 7.3.4).
- Material placed too wet, or wetted up after placement, cannot be compacted until back inside the specified range; drying or lime treatment costs sit with the contractor.

## Checks

- Laboratory independence in sampling/testing per TfNSW Q Annexure Q/L
- Each layer compacted full depth and conforming before the next layer starts (Clause 7.1)
- Rounding applied to 0.1% before comparison

## Common errors

- Pooling nuclear gauge and sand replacement results in one lot
- Averaging test values instead of computing the characteristic value per TfNSW Q
- Missing the higher compaction tier for spill-through abutment fill and Selected Material Zone layers
- Accepting lots whose moisture drifted outside the A5 range between placement and compaction

## Caveats

- Verify Ed 5 Rev 1 (or later) is the edition current for the project.
- Contract documents and Annexure R44/A entries override base values.

## Standards cited

TfNSW Q, TfNSW T111, TfNSW T162, TfNSW T166, TfNSW 3211
