# Photograph and label a core box

> **Source:** [Google Drive — Core Photo/IMG_0798.jpg, MP4-BH01.jpeg, IMG_0797.JPG](https://drive.google.com/file/d/1uarZXf5Idpz_yF858Z0Nu-2bJBYIJdvo/view) (Three core box photos, two boreholes on the same job: BH-4 (0-20.5m, end of core 20.44m) and BH20 (coring 9.5-19.98m); all show the STS board, colour chart, scale bar, metre tags and annotated spacer blocks). **Outcome.** A single composite photograph per core box that identifies the project, borehole and depth range, gives a true metric scale and colour reference, and lets every core run be located by depth.

## Inputs

- STS-branded core photo board (green/white board with QR code, colour reference patches and greyscale, 0.0m-1.0m checkered scale bar)
- Whiteboard marker for the board fields
- White spacer blocks and marker for in-box annotations
- Metre-number tags for each core row
- Core box with 1 m split trays

## Procedure

1. Fill in the board fields in marker: PROJECT NO. (office no./STS job no., e.g. 32904/2014E-G), CLIENT, ADDRESS, DATE, BOREHOLE NO., DEPTH (depth range covered, e.g. 0-20.5m or 19.8m).
2. Lay the board across the top of the core box so its 0.0-1.0m scale bar sits parallel to the core rows.
3. Tag the left end of each row with its starting depth in metres (rows in the records are tagged 5, 6, 7 ... 20).
4. Where coring does not start at surface, write the start on a white spacer at the first run (record shows '32904/2014E-G / 105 Hollinsworth rd / BH-20 / Marsden Park / 19/03/2026 / coring started from 9.5m').
5. Mark the end of the hole on a white spacer block placed in the tray at the finish point (records show 'END OF CORE - 20.44m' and 'Coring End at 19.98m').
6. Photograph square-on from above in daylight with the whole box, the board, the colour chart and every row tag in frame.
7. Name/file the photo by borehole (records use MP4-BH01.jpeg and IMG_ sequence numbers in the Core Photo folder).

## Decision rules

- One composite photo covers a whole box; deeper holes need one photo per box with the board DEPTH field updated to that box's range.
- Depth tags are written on the tray divider at the start of each 1 m run, so any stone in the photo can be depth-located against the board's scale bar.

## Checks

- Board fields legible in the photo and consistent with the drill log (project no., BH no., date, depth range).
- Colour chart and greyscale visible for later colour correction.
- End-of-core depth written in the box matches the driller's final depth.
- Every metre tag readable — the OCR of one record recovered all tags 0.0m-1.0m and 5-20 plus 'END OF CORE- 20.44m', which is the standard to aim for.

## Common errors

- Photographing at an angle so the scale bar cannot be used for measurement
- Board depth range not updated between boxes of the same hole
- Missing start-of-coring annotation when the hole is augered before coring
