# Size a rockfall catch ditch with the Ritchie chart

> **Source:** [YouTube — Rockfall Catch Ditch Design — Ritchie Chart Method](https://www.youtube.com/watch?v=Eof-qGDKfWo&t=0s) (00:00-05:51). A YouTube lecture — learning
> material, not an approved design procedure. Equations and numbers were
> heard through auto-captions; read them off the video before use, and
> verify anything design-relevant against the standard and the project
> specification. Engineering conclusions need qualified review.

**Outcome.** Required width and depth of a catch ditch at the toe of a rock slope, from slope height and slope angle

## Inputs

- Slope height from site survey
- Slope angle, computed from height and horizontal setback if not measured directly (tan alpha = height / horizontal distance)
- Ritchie ditch design chart (introduced by Ritchie, 1963)

## Procedure

1. Estimate slope height during site investigation (example: 20 m)
2. Compute the slope angle from geometry (example: tan alpha = 20/22.2 giving about 42 degrees)
3. Enter the Ritchie chart with slope height and slope angle and locate the design point
4. Read the required ditch width from the dashed-line family (example result: 4.57 m)
5. Read the required ditch depth from the solid-line family (example result: 1.83 m)
6. Where the point falls between chart lines, interpolate between the adjacent width values and the adjacent depth values
7. Detail the ditch base with soft material such as gravel to absorb impact energy of falling rocks

## Decision rules

- Width and depth both increase with slope height and depend on slope angle; always read both line families
- If the design point does not sit on chart lines, interpolate rather than rounding to the nearer line

## Checks

- Verify the computed slope angle against the chart axis range before reading values
- Confirm the ditch geometry is buildable at the site (excavation depth of the order of 1.8 m in the example)

## Common errors

- Reading only one line family and reporting width for depth or vice versa
- Skipping interpolation when the point falls between lines

## Caveats

- YouTube lecture — learning material, not an approved design procedure; verify against project specification and current standards
- Chart values quoted (4.57, 1.83, 2.13, 6.1 m) are imperial-derived line labels read on screen — read from the video
- Geology does not enter the chart; only slope height and inclination are used

## Standards cited

Ritchie (1963) ditch design chart (named by lecturer)
