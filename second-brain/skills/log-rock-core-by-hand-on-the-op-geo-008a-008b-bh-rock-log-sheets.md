# Log rock core by hand on the OP GEO 008a/008b BH rock log sheets

> **Source:** [Google Drive — Field Sheets (STS blank templates + reference)/OP GEO 008a RevA BH Rock log 5m.pdf and OP GEO 008b RevB BH Rock log 10m.pdf](https://drive.google.com/file/d/1gSvA4_vf799Y4kyiMl6--jAvKIJ9p3YA/view) (Blank EI-branded cored borehole log sheets with TCR/RQD columns, banded Is(50) inferred-strength scale and log-scale defect-spacing columns; coring observation practice from the EI logging guide sheet in the same folder). **Outcome.** A handwritten cored-borehole field log capturing core recovery, rock description, weathering, inferred strength and defect data against depth.

## Inputs

- OP GEO 008a RevA (5 m) or OP GEO 008b RevB (10 m) blank rock log sheet
- Header data as for the soil log (project, job no., contractor, drill rig, inclination)
- Core runs laid out in boxes with run markers
- Point load or field strength assessments per interval

## Procedure

1. Complete the same header block as the soil log (project, location, position, job no., client, contractor, drill rig, inclination, dates, sheet numbers).
2. For each core run record the Drilling columns: method, water observations, TCR (total core recovery) and RQD (SCR) against the run interval.
3. Mark depth and RL; draw the graphic log per lithology.
4. Describe rock in the standard order (ROCK NAME; grain size, colour, fabric/texture, inclusions or minor components, strength, weathering) in the Rock/Soil Material Description column.
5. Tick the Weathering column band (RS/XW/HW/DW/MW/SW/FR terms per the logging guide).
6. Mark inferred strength in the Is(50) MPa banded columns - the sheet prints bands from extremely low through extremely high keyed to point load index values (0.03, 0.1, 0.3, 1, 3, 10 MPa boundaries).
7. Record each defect in Defect Description & Additional Observations using the convention depth: type; angle, shape, roughness, coating, coating material (e.g. a bedding parting or joint entry), and plot Average Defect Spacing in the log-scaled mm columns (10 to 3000 mm).
8. During coring also note water return percentage and colour changes, and drilling rate changes per run - these flag weathering changes, clay-filled joints and core-loss zones.
9. Sign Logged and have Checked completed with dates.

## Decision rules

- TCR and RQD are recorded per run, not per lithology - keep run boundaries visible on the log.
- Strength is inferred in the field from pick/knife/hand behaviour and confirmed by Is(50) testing; tick the band, do not write a bare number without basis.
- Defects below the 100 mm size threshold use seam abbreviations, larger use zone abbreviations (per the EI logging guide convention).
- Sudden penetration-rate or water-return changes get an explicit note even if the core looks uniform.

## Checks

- TCR/RQD percentages consistent with what is actually in the core box (cross-check against core box photos).
- Every defect entry has depth, type and orientation at minimum.
- Weathering and strength ticks exist for the full cored depth with no unexplained gaps.

## Common errors

- Averaging defects mentally instead of using the average-defect-spacing columns, losing fracture-spacing data for design.
- Recording RQD without noting SCR basis where core is weak, overstating rock quality.
- Omitting water-return observations, which are hard to reconstruct after the shift.

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
