# Verify trench backfill compaction around drainage structures under R11

> **Source:** `r011.pdf` (Clauses 4.9.1-4.9.2, Tables R11.2 and R11.3 (Ed 5 Rev 2, Jan 2017)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** A drainage structure backfill lot is accepted or rejected against R11's relative compaction and layering rules, with the correct field density test method used.

## Inputs

- Lot definition (structure type, zone: bed/haunch/side/overlay, foundation, general backfill)
- Field density and moisture test results with laboratory maximum density
- Layer thickness records during placement
- Oversize fraction (% retained on 37.5 mm sieve) of the fill
- Concrete age/strength records if backfilling against cast-in-place structures

## Procedure

1. Identify which R11 compaction category the lot falls into (open drain surface, trench base/foundation, select fill around pipes, side/overlay of box culverts, or backfill within the adjoining Selected Material Zone) and read the minimum characteristic relative compaction from Table R11.2 (values range from 95% to 102%).
2. Confirm fill was placed in layers not exceeding the compacted thickness limit in Clause 4.9.1 (150 mm unless directed otherwise).
3. Select the field density test method from Table R11.3 based on the oversize fraction: nuclear gauge or sand replacement for low oversize, sand replacement only for intermediate oversize, fixed volume extractive for fine cohesionless materials; note the nuclear gauge is barred for layers thicker than 300 mm.
4. Compute the characteristic value of relative compaction statistically per Specification RMS Q and round to 0.1% before comparing with Table R11.2.
5. For backfill against concrete structures, verify timing rules in Clause 4.9.1 were met (minimum concrete strength fraction for cast-in-place box culverts, minimum elapsed days for other structures) and that fill levels on opposite sides of box culverts stayed within the differential limit.

## Decision rules

- If more than 40% by mass is retained on the 37.5 mm sieve, do not report relative compaction - the result is invalid (Table R11.3 note).
- If the characteristic relative compaction is below the Table R11.2 minimum for that zone, the lot is nonconforming.
- If backfill within the adjoining earthworks Selected Material Zone is involved, the higher R44-linked compaction standard in Table R11.2 governs, not the general backfill value.
- Compact fill next to the structure first and work outwards toward the excavation face to avoid wedge action (Clause 4.9.1).

## Checks

- One test method only used per lot for statistical assessment
- Layer thickness records consistent with the compacted thickness limit
- Moisture control documented so nearby earthworks are not wetted up
- Box culvert side/overlay zones backfilled with Type SO Select Fill, with the 1000 mm minimum select fill envelope and geotextile separation where inside rock fill embankments

## Common errors

- Using the nuclear gauge on layers thicker than 300 mm or on material with 20-40% oversize
- Applying the general backfill compaction value to box culvert side/overlay zones, which carry a higher requirement
- Backfilling against green concrete before the strength/age criteria are met
- Letting backfill on one side of a box culvert run ahead of the other beyond the differential limit

## Caveats

- Verify the spec edition (Ed 5 Rev 2 here) is current for the project before relying on values.
- Contract documents and project-specific annexures override the base specification.
