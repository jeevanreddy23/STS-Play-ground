# Log and describe rock core to the Look convention including RQD and defect description

> **Source:** `Handbook of Geotechnical Investigation and Design Tables_Bert Look 2014.pdf` (Chapter 3 Rock classification, Sections 3.1-3.16 (Tables 3.1 to 3.16, Figure 3.2), pp 33-43), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** Rock core logs that carry the weathering, strength, structure, RQD and defect information later chapters need for bearing capacity, excavatability and rock mass classification, with the RQD measured defensibly.

## Inputs

- Recovered core in trays, marked with depths and run boundaries
- Drilling record: bit type, barrel type, flush, water loss, penetration rate
- Field index tests (hammer/knife tests, point load index where available)
- Core photographs under consistent lighting with damped core
- Geological setting and expected rock types

## Procedure

1. Follow the Table 3.2 description sequence for the final log and the Table 3.3 field log layout. Log at the rig as core is recovered - Look points out that the relatively slow recovery rate makes real-time logging practical, and that RQD taken from a box after handling is not the same measurement.
2. Record drilling equipment with the Table 3.4 symbols and note bit type changes; Chapter 6 later reads strength implications from what the rig could and could not penetrate, so the drilling record is a strength record.
3. Assign weathering grade from Table 3.5. Weathering is the descriptor most likely to be assessed and is the usual quick proxy for strength, but note residual soil is a weathering product and not a rock type, that distinctly weathered may be split into highly and moderately weathered, and that weathering depth varies with aspect.
4. Describe rock structure and discontinuity spacing/thickness with Table 3.7 and Table 3.12, including persistence as a measure of joint continuity.
5. Measure RQD per Table 3.8 and Figure 3.2. Exclude drilling-induced fractures. Measure over a structural domain rather than over an arbitrary core run. Record that RQD is orientation dependent - an inclined hole through a dominant joint set gives a different value from a vertical one.
6. Assign intact rock material strength from Table 3.9 by field index test, and record hardness separately using Table 3.10 - Look is explicit that hardness is not strength.
7. Describe defects with Table 3.13 descriptors and Table 3.14 symbols: type, orientation, roughness, planarity, aperture, infill, coating. These feed directly into joint friction (Chapter 9) and rock mass rating (Chapter 18).
8. Assign rock type from Table 3.15 (sedimentary and pyroclastic) or Table 3.16 (metamorphic and igneous), using grain size and fabric.
9. Use Table 3.11 to keep discontinuity scale effects in view when generalising from core to rock mass - the scale bands overlap by an order of magnitude.
10. Photograph core with even lighting, no shadows and damp surfaces, with a scale and colour reference, before the core dries or degrades.

## Decision rules

- Never include drilling breaks in RQD; where the origin of a break is ambiguous, record it and state the assumption.
- Compute RQD over a domain of consistent structure; averaging across a domain boundary produces a number that describes neither.
- A more weathered rock can have higher intact strength than a less weathered one of a different type - weathering grade alone must not set a bearing pressure (Section 6.9).
- Continuity of a discontinuity is relative to the structure, load and cut being assessed - a defect is continuous under a footing if it is at least as long as the loaded dimension.
- Weathered shales, siltstones and sandstones can degrade rapidly on exposure; log them and specify blinding or protection of the exposed founding surface.

## Checks

- RQD recomputed independently on a sample of runs, with drilling breaks excluded
- Core recovery, solid core recovery and RQD all reported, not RQD alone
- Defect descriptions complete enough to support later joint-friction selection (roughness, infill, aperture)
- Weathering grades consistent between adjacent holes at similar elevations
- Core photographs taken before any degradation of exposure-sensitive rock

## Common errors

- Counting handling breaks as natural defects and understating RQD
- Logging weathering grade and treating it as a direct strength or bearing value
- Using hardness terms interchangeably with strength terms
- Logging from the box hours later, after core has dried and pieces have separated
- Omitting persistence and infill descriptors that later control the joint shear strength selection

## Caveats

- Reference text, not a design standard - verify against the source pages and Australian practice before use.
- Rock type descriptors are adapted from AS 1726-1993 and other sources; check against the current standard edition.
- Symbol sets vary between consultants and authorities - map to the project convention and publish the legend.
