# Estimate the diggability index and class for weathered rock

> **Source:** [YouTube — How to Choose Rock Excavation Methods — Digging, Ripping or Blasting](https://www.youtube.com/watch?v=9W1vB1dhc5w&t=274s) (04:34-08:57). A YouTube lecture — learning
> material, not an approved design procedure. Equations and numbers were
> heard through auto-captions; read them off the video before use, and
> verify anything design-relevant against the standard and the project
> specification. Engineering conclusions need qualified review.

**Outcome.** A diggability index and class that indicates how easily a weathered rock mass can be dug and guides equipment and cost planning

## Inputs

- Degree of weathering description
- Strength (UCS or point load index)
- Joint spacing (reciprocal of discontinuity frequency)
- Bedding spacing where bedding exists
- Diggability rating table with index points per category and class boundaries

## Procedure

1. Work down the table assigning index points for each row: weathering, strength, joint spacing, bedding spacing
2. Example scoring: heavily weathered sandstone scored 5 for weathering; UCS of 7 MPa (below the 20 MPa threshold) scored 0 for strength; 10 fractures per metre gives 0.1 m spacing, below 0.3 m, scoring 5; bedding spacing 0.1 m scored 5
3. Sum the points to get the diggability index (example total 15)
4. Read the class from the index bands (example: index below about 40 is class 1, very easy digging)

## Decision rules

- Either UCS or point load index can enter the strength row — use whichever was measured
- When a value sits exactly on a category boundary, take the slightly more adverse category
- Low classes mean cheaper, faster excavation; difficult or extremely difficult classes prompt more budget or a different excavation method

## Checks

- Confirm spacing values were converted from fracture counts correctly (spacing = 1 / joints per metre)
- Confirm every applicable row was scored, including bedding only where bedding planes exist

## Common errors

- Skipping the bedding row when bedding is present, or scoring it when there is none
- Treating boundary values optimistically instead of conservatively

## Caveats

- YouTube lecture — learning material, not an approved design procedure; verify against project specification and current standards
- Point values and class boundaries come from the on-screen table — read from the video
