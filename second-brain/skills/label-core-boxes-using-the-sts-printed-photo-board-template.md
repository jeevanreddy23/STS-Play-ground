# Label core boxes using the STS printed photo-board template

> **Source:** [Google Drive — Field Sheets (STS blank templates + reference)/Core Box Label.pptx; Core Photos (MP4 compilation)/MP4-BH01.jpeg; Photos (Nov 2021 site photo dump)/IMG20211126131944.jpg](https://drive.google.com/file/d/1qEsHuXWIxTp9NDT1IswJ3xK-lWfp_dES/view) (The 9-slide pptx template (six-field table, 0.0-1.0 m scale bar at 0.1 m graduations, logo, QR code, office-address strip); a 2026 core photo showing the printed board filled in marker with colour chart, per-row depth numbers and 'Coring End at 19.98m'; a 2021 photo showing the legacy handwritten-strip/metre-block/tape-measure method). **Outcome.** Every core box is photographed behind a standard printed STS board identifying project, client, address, date, borehole and depth, with a 1 m graduated scale bar and colour reference, and with depth progress marked inside the box, so any core photo is self-identifying and dimensionally interpretable.

## Inputs

- Core Box Label.pptx template (STS branded, multiple layout variants)
- Printer / laminated board stock for the label
- Permanent marker for handwriting job details
- Core box with recovered core runs placed in depth order

## Procedure

1. Print the label board from the PowerPoint template; the slide carries a six-field table (PROJECT NO, CLIENT, ADDRESS on the left; DATE, BOREHOLE NO, DEPTH on the right), the STS Geotechnics logo, a QR code, and a full-width 1 m scale bar graduated at 0.1 m intervals from 0.0 m to 1.0 m.
2. Hand-fill the six fields in marker for the box being photographed: project number, client, site address, photo date, borehole ID, and the depth (total or box depth range).
3. Place the board across the top of the core box together with the colour/greyscale calibration chart so both appear in frame with the core.
4. Inside the box, mark depth progress on the tray dividers or spacer blocks (metre marks per row) and write the termination on the last row (e.g. 'Coring End at 19.98 m').
5. Keep a handwritten strip in the first tray repeating job number, address, borehole ID, date and run start depth as a backup identification independent of the board.
6. Photograph the box square-on from above with board, scale bar, colour chart and all trays fully in frame.

## Decision rules

- Choose the template slide variant that matches the box format being photographed; all variants keep the same six identification fields and 1 m scale bar.
- If a printed board is not available on site, fall back to the legacy manual method: handwritten strip along the box edge (job no, site, BH, date, initials, START depth), white spacer blocks at each metre, an END block at termination depth, and a tape measure laid along the core for scale.
- Depth field on the board records how deep the hole/box extends; the in-box end-of-coring note records the exact termination depth to two decimals.

## Checks

- All six board fields are legible in the final photo and agree with the borehole log for the same hole and date.
- Scale bar and colour chart are unobstructed so measurements and colour can be corrected from the image.
- In-box depth marks run consecutively with no missing metres, and the end-of-coring depth matches the logged termination depth.

## Common errors

- Leaving board fields blank or filling them after the photo, breaking the link between image and hole
- Cropping the scale bar or colour chart out of frame, making the photo unusable for measurement
- Depth on the board disagreeing with the handwritten in-box strip or the borehole log
- Photographing at an oblique angle so the scale bar cannot be used across the full box width

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
- The core-box PHOTO practice (photographing with the STS photo board) was mined separately; this skill covers producing and completing the label board itself and marking depths inside the box
- Purpose of the QR code on the board is not evidenced in the records
