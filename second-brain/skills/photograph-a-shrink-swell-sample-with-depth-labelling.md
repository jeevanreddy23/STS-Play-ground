# Photograph a shrink-swell sample with depth labelling

> **Source:** [Google Drive — Shrink Swell photo/BH1 0.7-1.0m.jpg](https://drive.google.com/file/d/1g3tBM2nLEioR04xqmowsK0xW6Pa840Ru/view) (Tray photo of an undisturbed sample with handwritten card '31380/8008D-L / S1, BH1 0.7-1.0m / S/swell'). Reconstructed from STS's own
> field records on Google Drive — completed forms, labelled photos and
> scans, catalogued in [[Field records catalogue]]. It shows what the
> records evidence, not necessarily the current approved procedure —
> confirm against the current STS form and procedure before treating it
> as the standard method.

**Outcome.** A photographic record tying an undisturbed sample to its job number, borehole, depth interval and the laboratory test it is allocated to, before it leaves the field/sample store.

## Inputs

- Undisturbed tube sample (extruded core segment and/or capped tube ends)
- Card or paper label and pen
- Tray to contain the sample and label in one frame

## Procedure

1. Write a card with three lines: job number / STS number (e.g. 31380/8008D-L), sample and location with depth interval (e.g. 'S1, BH1 0.7-1.0m'), and the allocated test written as 'S/swell' for shrink-swell.
2. Place the sample components (extruded core, tube ring, capped end) and the card together in a clean tray.
3. Photograph from directly above with the card legible and the sample condition visible.
4. Name the image file with the borehole and depth interval exactly as on the card (file is 'BH1 0.7-1.0m.jpg').
5. File in the Shrink Swell photo folder.

## Decision rules

- The filename must repeat the label (BH + depth interval) so the photo can be found without opening it.
- Photograph before any trimming/testing so the as-received condition (roots, moisture, layering visible in the record) is documented.

## Checks

- Card text legible in the photo: job/STS number, sample ID, BH, depth interval, test allocation.
- Depth interval on card, filename and the borehole log all agree.

## Common errors

- Photographing the sample without the identification card in frame
- Filename not matching the labelled depth interval, breaking traceability

## Caveats

- Reconstructed from STS field records — confirm against the current STS procedure before treating as the standard method
- Based on a single example photo; the card line order may vary
