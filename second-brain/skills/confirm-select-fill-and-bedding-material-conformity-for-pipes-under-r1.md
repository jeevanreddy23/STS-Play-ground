# Confirm select fill and bedding material conformity for pipes under R11

> **Source:** `r011.pdf` (Clauses 3.1-3.2, 4.4.1, 2.6; Annexure R11/L (Ed 5 Rev 2)), held in the local reference library — see
> [[Reference library]]. This note is a paraphrased working aid, not the
> document. Values, clauses and criteria must be read from the source before
> they are relied on, and engineering conclusions need qualified review.

**Outcome.** Bedding and support fill materials are demonstrated conforming, at the specified testing frequency, before placement around pipes and culverts.

## Inputs

- Material source and stockpile identification
- Particle size distribution and Plasticity Index test results
- Placement volumes per material type
- Drawings/AS 3725 support type requirements

## Procedure

1. Classify the material by zone: Type BH Select Fill for bed and haunch zones, Type SO Select Fill for side and overlay zones, and the clean crushed stone/gravel requirement for material adjacent to weepholes (Clauses 3.1-3.2).
2. Check Type BH against its grading envelope (referenced to AS 3725 / AS 1597.2 tables) and its Plasticity Index ceiling; check Type SO against its maximum particle dimension and PI band (Clause 3.1).
3. Confirm pipe support is the specified type (HS3 per AS 3725 and the RMS model drawing) and that flowable fill is used at pipe connections where required (Clause 4.4.1).
4. Verify testing frequency against Annexure R11/L: PSD and PI tests are required per fixed volume increments of material placed (different rates for BH vs SO zones), all prior to placement.
5. Obtain the supplier/contractor certificate of conformity before the material or manufactured product is incorporated (Clause 2.6 Hold Point).

## Decision rules

- Material failing grading or plasticity limits must not be placed in the nominated zone - reassign or reject.
- If testing frequency in Annexure R11/L has not been met for the volume placed, the lot lacks conformity evidence regardless of the results in hand.
- Weephole-adjacent material must meet the maximum particle size and the fines limit on the 9.5 mm sieve; ordinary select fill is not a substitute.

## Checks

- Test methods match those nominated (RMS T201 for grading, RMS T109 for plasticity)
- Sampling was done prior to placement, not retrospectively
- Certificates of conformity are on file as identified records

## Common errors

- Using one combined stockpile for BH and SO zones without testing to the stricter BH frequency
- Overlooking the flowable fill requirement at pipe connections
- Treating the Annexure R11/L frequencies as targets rather than minimums per volume placed or part thereof

## Caveats

- Verify the spec edition is current for the project before relying on values.
- Contract documents and project-specific annexures override the base specification.

## Standards cited

AS 3725, AS 1597.2, RMS T109, RMS T201, RMS 3051
