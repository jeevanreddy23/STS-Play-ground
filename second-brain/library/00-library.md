# Reference library

A catalogue of the geotechnical reference material held locally, so it can be
found from the notes that use it.

**These are pointers, not copies.** The standards, papers and textbooks are
licensed or copyright material and are not reproduced in this vault — the notes
record what a document covers and where it sits, and the document itself stays
where it is. Anything relied on for a job is read from the source.

Local root: `C:\Users\pored\Downloads\G materials`
