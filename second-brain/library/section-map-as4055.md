# Section map — AS 4055:2012

Wind loads for housing. The simplified route to a wind classification (N1–N6,
C1–C4) for NCC Class 1 and 10 buildings inside the geometric limits of
Clause 1.2 — reached for when a site inspection has to return a wind class
alongside the site classification, from region plus terrain category, topographic
class and shielding class. Houses outside those limits go to AS/NZS 1170.2
instead. Local copy: `G materials/4055-2012.pdf`
— see [[Reference library]].

## Extraction note

Headings were read from the local PDF's contents page and are limited to two
levels. Section 4 (Uplift forces) is a single unnumbered block in the contents,
which is how the standard is set out rather than a gap in extraction.

The four clauses a field engineer actually uses are 2.2 to 2.5 — region and
site conditions, terrain category, topographic class, shielding class — with the
worked examples in Appendices B and C settling the borderline calls. Clause 1.2
is the gate: check the eaves and ridge heights and roof geometry against it
before quoting a class at all.
