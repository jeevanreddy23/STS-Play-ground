# Library - plate load testing

`G materials/Plate Load Testing/`. Procedure, computation spreadsheets and
training for the light and dynamic plate load kit.

| File | What it is |
|---|---|
| `050-Setup Proceedure for PLT Draft 4 Feb 2024.docx/.pdf` | Our setup procedure — draft status, check before relying on it |
| `ax_v80_en.xltm` | Manufacturer computation template |
| `AX01a recommended Loading Stages 6/7.xlsx` | Loading stage schedules |
| `PLT Calculations for AX01a.pdf`, `Calculations.pdf` | Worked computation |
| `Relationship Between Ev2 and Evd.xlsx` | Static-to-dynamic modulus correlation |
| `AX01 Sample Results with GPS.pdf/.xlsm` | Sample output with positions |
| `BedAnlAx01a_engl V40a.pdf` | Equipment manual |
| `PLT Training Presentation.pptx`, `PLT Electronic Menu Structure Training.pptx` | Training |

## Caution

The Ev2/Evd relationship is a correlation, not an identity, and it is
material-dependent. Reporting a dynamic result as if it were a static modulus
without stating the correlation is the same class of error described in
[[DCP testing]].
