# Library - reference texts and parameter sources

Where a parameter comes from when it is not measured on the job. Every value
taken from here is a published correlation, not a site measurement, and is
recorded as such — see [[Why pile data carries provenance]].

| Source | Use |
|---|---|
| Look, *Handbook of Geotechnical Investigation and Design Tables* (2014) | First stop for indicative parameters and correlations |
| `Correlations of Soil Properties.pdf` | Correlation compendium |

| Das, *Principles of Geotechnical Engineering* (8th ed.) | General reference |
| Lambe & Whitman, *Soil Mechanics* | Fundamentals |

| `Earth pressure calculations.xlsx` | Retaining wall pressures |
| `Working Platforms for tracked plant.pdf` | Working platform design for piling rigs |

## The discipline that matters here

A correlation is valid for the material and test it was derived from. Carrying
an SPT-based capacity into a rock socket, or a sand correlation into clay,
produces a confident number with no basis. State the source and the assumed
material whenever one of these is used.
